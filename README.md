When you run **`FortnitePrivateServer.exe`**, you get a menu with:

**1. Install Server** — Automatically downloads and extracts LawinServer, Neonite, and FortniteBuilds to the right folders.

**2. Select Build** — Choose your Fortnite version (Season 1 through Season X).

**3. Launch Launcher** — Opens Carbon Launcher or EasyLauncher, pre-configured for your build.

**4. Start Server** — Starts the local backend (LawinServer or Neonite) on `127.0.0.1`.

**5. Inject Cheat** — Loads the cheat menu into Fortnite (works only after server is running).
